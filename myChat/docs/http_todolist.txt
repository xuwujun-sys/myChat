简单 HTTP 文件服务器待办清单

目标：在现有 TCP 服务器上实现简单的文件下载和上传，逐步添加功能。
第一版使用 HTTP/1.1 的有限功能，每个连接处理一个请求，响应发送完后关闭。
文件上传先使用 PUT 和原始请求体，暂不实现浏览器上传表单。

[x] 1. 准备通用网络底层
    [x] 复用 Kernel、TcpChannel 和 Handler 接口
    [x] 待发送数据加入空队列时通知事件循环

[x] 2. 创建 HttpHandler，返回固定 HTTP 响应
    [x] 实现 Handler 接口，在 main 中选择 HttpHandler
    [x] 返回状态行、响应头、空行和固定内容
    [x] 支持响应发送完成后关闭连接，避免丢失待发送数据
    [x] 验证：curl 能收到完整响应，回显服务仍能切换使用

[x] 3. 解析 HTTP 请求
    [x] 为每个连接保存接收状态，断开连接时清理
    [x] 累积数据直到遇到请求头结束标记，处理分多次接收的情况
    [x] 使用简单的 HttpRequest 保存请求方法、路径和必要请求头
    [x] 统计同次或分次到达的请求体长度，限制请求头大小
    [x] 校验请求行、Host 和 Content-Length；错误请求返回适当状态码
    [x] 验证：分段发送请求头、非法请求及多个客户端互不干扰

[x] 4. 实现小文件下载
    [x] 支持 GET /files/文件名，从指定目录读取文件
    [x] 返回正确状态码、Content-Length 和文件内容
    [x] 文件不存在时返回 404；限制路径访问，防止越过文件目录
    [x] 验证：curl 下载后比较文件内容，包括空文件和二进制文件

[x] 5. 实现小文件上传
    [x] 支持 PUT /files/文件名，按 Content-Length 接收原始请求体
    [x] 限制文件大小；拒绝非法文件名、非法长度和不支持的请求编码
    [x] 上传中断或写入失败时清理未完成文件；成功后返回响应
    [x] 验证：curl 上传后比较文件内容，检查中断和非法请求

[x] 6. 支持大文件分块传输
    [x] 下载时分块读取，缓冲区有空间后继续，不能超过当前 1 MB 上限
    [x] 增加必要的发送进度通知，确保最后一块发送完后再关闭连接
    [x] 上传时按块写入，限制内存占用，不把整个文件保存在内存中
    [x] 验证：上传和下载超过 1 MB 的文件，比较内容并测试慢速接收

[ ] 7. 整体检查
    [x] 验证并发客户端、连接中断、错误请求、资源释放和回显功能
    [x] 为请求处理和文件操作补充空闲超时、大小限制和错误处理
    [ ] 在实际磁盘上进一步压测读写延迟，再决定是否需要工作线程（当前为同步读写）

[x] 8. 文件管理页面：查看共享文件、上传和下载，适配桌面和手机

以后按需要考虑：HTTP 持久连接、chunked、浏览器上传表单、HTTPS 和断点续传。
