ChatRoom 第一阶段待办清单

目标：基于现有网络底层，实现局域网多人群聊，
使用简单终端客户端完成联调。

[ ] 1. 约定聊天协议
    [ ] 使用文本命令，每条消息以 \n 结束
    [ ] 定义设置昵称、发送群聊消息和服务器响应的格式
    [ ] 规定昵称和消息长度上限，处理非法输入
    [ ] 处理半包和多条消息一起到达的情况

[ ] 2. 实现 ChatHandler
    [ ] 复用现有 Handler 接口
    [ ] 为每个连接保存昵称和未接收完整的数据
    [ ] 客户端设置昵称后加入在线列表，拒绝重复昵称
    [ ] 收到完整群聊消息后，转发给其他在线用户
    [ ] 客户端断开时清理连接和用户状态

[ ] 3. 处理聊天连接
    [ ] 调整现有 60 秒空闲超时，使用户不发言时不会意外断线
    [ ] 处理发送失败、消息过长和异常断开
    [ ] 保证断开后不会再使用失效的连接

[ ] 4. 实现简单终端客户端
    [ ] 连接服务器并设置昵称
    [ ] 输入和发送群聊消息
    [ ] 接收并显示其他用户的消息
    [ ] 显示连接失败或断开的提示

[ ] 5. 联调验证
    [ ] 两个以上客户端连接并互发消息
    [ ] 验证昵称重复、非法输入和消息过长
    [ ] 验证分段发送和多条消息同时到达
    [ ] 一名客户端退出后，其他客户端仍能正常聊天
    [ ] 验证长时间不发言后连接仍可使用

第一阶段暂不实现私聊、离线消息、账号密码和 Qt 界面。
完成标准：多个终端客户端能稳定群聊，用户退出后其他人不受影响。
