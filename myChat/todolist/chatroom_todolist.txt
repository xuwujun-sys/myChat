直接使用 Qt 客户端，按功能交替完善服务器和客户端，每完成一小步就联调验证。

[x] 1. 约定聊天协议
    [x] 使用文本命令，每条消息以 \n 结束
    [x] 定义设置昵称、发送群聊消息和服务器响应的格式
    [x] 规定昵称和消息长度上限，处理非法输入
    [x] 处理半包和多条消息一起到达的情况

    [x] 收到完整群聊消息后，转发给其他在线用户
    [x] 客户端断开时清理连接和用户状态

    [ ] 处理发送失败、消息过长和异常断开
    [ ] 保证断开后不会再使用失效的连接

[ ] 4. 联调验证
    [ ] 两个以上 Qt 客户端连接并互发消息
    [ ] 验证昵称重复、非法输入和消息过长

第一阶段暂不实现私聊、离线消息和账号密码，Qt 界面先满足基本群聊。
