ChatRoom Qt 客户端待办清单

目标：使用 Qt Widgets 和 QTcpSocket 实现简单的局域网群聊客户端。
开发方式：每次完成一个功能点，与现有服务器联调后再继续下一步。

[ ] 1. 创建工程并连接服务器
    [ ] 创建 Qt Widgets 工程，使用 Qt Network 模块
    [ ] 提供服务器地址、端口输入框和连接按钮
    [ ] 使用 QTcpSocket 连接，显示连接成功、失败和断开状态
    [ ] 验证：可以连接现有聊天服务器，不阻塞界面

[ ] 2. 设置昵称
    [ ] 提供昵称输入框，按现有协议发送 LOGIN 昵称\n
    [ ] 缓存接收数据，按换行提取完整响应，处理半包和粘包
    [ ] 处理 OK LOGIN 和 ERROR 响应，显示昵称重复等错误
    [ ] 昵称校验遵循服务器规则，UTF-8 编码后不超过 32 字节
    [ ] 验证：登录成功后才能发送聊天消息，昵称重复时可修改后重试

[ ] 3. 实现群聊收发
    [ ] 增加聊天记录区域、消息输入框和发送按钮
    [ ] 按 MSG 消息内容\n 发送，校验空内容、控制字符和 1024 字节上限
    [ ] 解析 CHAT 昵称 消息内容\n，保留消息内容中的空格
    [ ] 按纯文本显示收到的消息，并在本地显示自己提交发送的消息
    [ ] 限制未完成响应行的缓存长度；服务器响应最长 1062 字节，不含换行
    [ ] 验证：两个 Qt 客户端互发中文、空格和接近长度上限的消息

[ ] 4. 完善连接与错误提示
    [ ] 处理写入失败、服务器 ERROR、服务器退出和异常断线
    [ ] 断开时清理接收缓存和登录状态，禁用发送按钮
    [ ] 支持手动重新连接，并重新设置昵称
    [ ] 验证：重连后不混入旧连接的数据或登录状态

[ ] 5. 整体联调
    [ ] 多个客户端互发消息，确认服务器不回发给发送者
    [ ] 验证重复昵称、非法输入、中文字节限制和分段响应
    [ ] 退出一个客户端后，其他客户端仍能聊天，昵称可以重新使用
    [ ] 长时间不发言后仍能正常收发，窗口保持响应

先完成基本群聊，暂不加入私聊、离线消息、账号密码和复杂界面。
协议以 apps/chat/protocol.txt 为准。
